# Tick

> **A modern, offline-capable PWA task manager** — organize your day with speed and style.

![Version](https://img.shields.io/badge/version-1.0.0-orange?style=flat-square)
![PWA](https://img.shields.io/badge/PWA-ready-blue?style=flat-square)
![License](https://img.shields.io/badge/license-MIT-green?style=flat-square)

---

## ✦ Features

- **Full CRUD** — Create, edit, complete, delete tasks — instant & fluid
- **Smart views** — All, Today, Important, Planned — filter what matters
- **Categories** — General, Work, Personal, Health, Finance, Education
- **Priorities** — High, Medium, Low with color-coded indicators
- **Search & Sort** — Real-time search, sort by date / priority / name
- **Dark mode** — System-aware, toggle anytime
- **i18n** — English & Persian (RTL) — seamless language switch
- **Drag & drop** — Reorder tasks by hand
- **Undo delete** — 5-second grace window before permanent removal
- **Browser notifications** — Reminders for tasks due today
- **Progress stats** — Total, Active, Completed, Overdue counts + bar
- **Offline-first** — Service worker caches everything; works without internet
- **Installable** — Add to home screen as a standalone PWA
- **Zero dependencies** — Vanilla JS, Tailwind CDN — no build step

---

## ✦ Quick Start

```bash
git clone https://github.com/your-username/tick.git
cd tick
# Serve with any HTTP server — no build needed
npx serve .
```

Open `http://localhost:3000` and start ticking.
